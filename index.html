수업 스케줄 자동 생성기

근무 가능 시간을 설정하고, 회원 신청을 받아 겹치지 않는 스케줄 후보를 자동으로 생성합니다.

기본 설정

한 번 설정해두면 되는 기본 정보예요. 필요할 때만 이 페이지에서 수정하면 됩니다.

근무 가능 시간

요일별로 근무 여부와 시작~종료 시간을 선택해주세요.

지점 등록

근무하는 지점을 등록하고, 지점 쌍마다 실제 이동에 걸리는 시간을 입력해주세요. 후보 생성 시 이동 시간이 부족하면 해당 조합은 배정되지 않습니다.

스케줄 생성

겹치지 않는 스케줄 후보를 생성하세요.

  • 정해진 스케줄은 다른 스케줄과 겹칠 수 없습니다.
  • 스케줄과 이동시간은 겹칠 수 없습니다.
  • 각 회원은 1일 최대 1회의 스케줄을 가질 수 있습니다.
  • 각 회원은 최대 2회까지의 스케줄을 가질 수 있습니다. (상담 회원의 경우 최대 1회까지)
  • 1회 제한 회원에 선택된 회원은 수업 스케줄 생성 시 스케줄이 최대 1회까지 배정됩니다.
  • 하루 이동은 최소화하며, 이동할 경우 최대 2회까지로 제한합니다.
  • 이동시간을 제외한 빈 시간은 없도록 합니다. (단, 빈 시간을 허용해서 수업의 횟수가 늘어난다면 10분까지 허용합니다.)
  • 각 회원은 최대한 1회 이상의 스케줄을 가질 수 있도록 합니다.
  • 인원을 최대화하도록 배정합니다.
    • 동점일 경우, 수업 횟수가 많은 쪽을 우선합니다.
    • 그마저 동점일 경우, 이동 횟수가 적은 쪽을 우선합니다.
    • 그마저 동점일 경우, 이동 시간이 적은 쪽을 우선합니다.
    • 그마저 동점일 경우, 총 이동시간과 빈 시간의 합이 적은 쪽을 우선합니다.

수업 스케줄 생성3

겹치지 않는 스케줄 후보 3개(후보A·B·C)를 한 화면에서 생성하세요.

  • 후보A는 "수업 스케줄 생성2"와 같은 방식(체인 DP + 다듬기)으로 만듭니다.
  • 후보B·C는 "수업 스케줄 생성1"의 후보A(인원 최대)·후보B(수업 횟수 최대)와 같은 방식(그리디)으로 만듭니다.
  • 정해진 스케줄은 다른 스케줄과 겹칠 수 없습니다.
  • 스케줄과 이동시간은 겹칠 수 없습니다.
  • 각 회원은 1일 최대 1회의 스케줄을 가질 수 있습니다.
  • 각 회원은 최대 2회까지의 스케줄을 가질 수 있습니다. (상담 회원의 경우 최대 1회까지)
  • 1회 제한 회원에 선택된 회원은 스케줄이 최대 1회까지 배정됩니다.
  • 여기서 선택한 미배정 회원 · 1회 제한 회원 설정은 후보A·B·C 모두에 똑같이 적용됩니다.

회원 스케줄 추가

회원별로 요일과 시작 시간을 선택해 가능 시간을 추가하세요. 회원 등록은 회원관리 메뉴에서 합니다.

가능 시간 설정

회원을 선택한 뒤, 시간 추가 가능합니다. 등록된 시간에 마우스를 올리면 나타나는 × 버튼으로 삭제 가능합니다.

등록 예시)

  • 17시 수업만 가능할 경우: 17:00~17:00
  • 17시까지만 가능할 경우: 선택안함~17:00
  • 17시부터 가능한 경우: 17:00~선택안함
등록된 회원이 없습니다.

붙여넣기로 일괄 등록

기존에 등록된 스케줄은 그대로 두고 붙여넣은 내용만 추가할까요, 아니면 전체 스케줄을 초기화한 뒤 등록할까요?

붙여넣기로 일괄 등록

한 줄에 회원 한 명씩, "이름 요일시간..." 형식으로 붙여넣으세요. 요일과 시간은 띄어쓰기 없이 이어 써도 됩니다.

작성 규칙)

  • 요일은 이어 붙여 쓸 수 있습니다. (예: 화목)
  • 시간은 오후 기준 시각이며, 숫자를 이어 쓰면 각각 정시로 등록됩니다. (예: 7 → 19:00, 730 → 19:30, 5678 → 17:00·18:00·19:00·20:00)
  • 숫자 사이에 물결(~)을 넣으면 그 사이 매시가 전부 등록됩니다. (예: 3~6 → 3456과 동일)
  • 시간 끝에 물결을 붙이면 그 시각부터 마감 시간까지 전부 가능한 것으로 등록됩니다. (예: 6630~ → 18:00, 그리고 18:30부터 마감까지)
  • 이름 뒤에 x만 쓰면 그 회원의 기존 가능 시간을 모두 삭제합니다(등록 안 한 것처럼 초기화). (예: 홍길동 x)

예시)

  • 홍길동 월화수5678
  • 홍길동 화목금5530
  • 홍길동 월화6630~ 금1~
  • 홍길동 수목3~6
  • 홍길동 x

모든 데이터는 이 브라우저에만 저장됩니다 (localStorage).
