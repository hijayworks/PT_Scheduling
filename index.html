수업 스케줄 자동 생성기

근무 가능 시간을 설정하고, 회원 신청을 받아 겹치지 않는 스케줄 후보를 자동으로 생성합니다.

변경사항을 브라우저에 저장하지 못했습니다. 페이지를 닫거나 새로고침하면 최근 변경사항이 사라질 수 있습니다. 저장 공간이나 브라우저 설정을 확인한 뒤, 가능하면 백업 코드를 만들어 보관하세요.

기본 설정

한 번 설정해두면 되는 기본 정보예요. 필요할 때만 이 페이지에서 수정하면 됩니다.

근무 가능 시간

요일별로 근무 여부와 시작~종료 시간을 선택해주세요.

지점 등록

근무하는 지점을 등록하고, 지점 쌍마다 실제 이동에 걸리는 시간을 입력해주세요. 후보 생성 시 이동 시간이 부족하면 해당 조합은 배정되지 않습니다.

지점 간 이동 시간 (분)

데이터 백업 · 복원

모든 데이터는 이 브라우저에만 저장되어 다른 기기·브라우저와 자동으로 공유되지 않습니다. 다른 기기에서도 같은 데이터를 쓰고 싶을 때, 여기서 백업 코드를 만들어 복사한 뒤 그 기기에서 붙여넣어 복원하세요. 백업 코드는 백업 비밀번호로 암호화되어, 비밀번호를 모르면 코드만으로는 내용을 볼 수 없습니다. 새 백업 비밀번호는 12자 이상을 사용하세요.

수업 스케줄 생성

겹치지 않는 스케줄 후보를 만들고, 장단점이 실제로 다른 후보끼리 비교해 고르세요.

  • 배정 규칙 (모든 후보가 항상 지킵니다)
    • 회원이 신청한 요일·시간, 허용된 지점, 근무 가능 시간 안에서만 배정합니다.
    • 수업 시간은 등록 회원 60분, 상담 회원 30분입니다.
    • 수업끼리는 겹치지 않으며, 다른 지점으로 옮길 때는 이동시간만큼 간격을 둡니다. 이동시간이 등록되지 않은 두 지점은 같은 날 이어서 배정하지 않습니다.
    • 각 회원은 하루 최대 1회, 주 최대 2회까지 배정됩니다. 상담 회원과 1회 제한 회원은 주 최대 1회까지입니다.
    • 하루 지점 간 이동은 최대 2회까지이며, 가능한 한 줄입니다.
    • 미배정 회원으로 선택한 회원은 배정하지 않습니다. 미배정 회원 · 1회 제한 회원 설정은 모든 후보에 똑같이 적용됩니다.
  • 후보 비교
    • 여러 방식으로 후보를 만든 뒤 미배정 → 비효율 이동 → 수업 수·이동 횟수·빈 시간 순으로 비교해 가장 나은 후보를 '추천'으로 항상 보여줍니다.
    • 비효율 이동은 같은 날 다른 지점에 갔다가 원래 지점으로 되돌아오는 왕복입니다. (마포점↔여의도점 왕복은 제외)
    • 추천보다 그 지표가 실제로 나은 후보가 있을 때만 '수업 우선'(수업 수)·'이동 최소'(이동 횟수)·'공강 최소'(빈 시간) 카드가 이 순서대로 추가됩니다. 자동 후보는 추천 포함 최대 3개입니다.
    • 그래서 '추천'만 나올 수도 있고, '추천 + 수업 우선', '추천 + 공강 최소'처럼 일부만 나올 수도 있습니다.
    • 추천 후보보다 미배정 회원이 많아지는 후보는 보여주지 않습니다.
    • 장단점이 같지만 배정이 다른 배치는 카드 안에서 넘겨 볼 수 있습니다.
  • 직접 수정
    • 직접 수정하거나 확정한 후보는 '내가 수정한 후보'로 따로 보이며, 다시 후보를 생성해도 유지됩니다. 회원·신청·설정이 바뀌면 함께 초기화됩니다.
    • '나머지 일정 다시 최적화'는 수정하거나 확정한 수업은 유지한 채 나머지 일정만 다시 탐색합니다.

붙여넣기로 일괄 등록

기존에 등록된 스케줄은 그대로 두고 붙여넣은 내용만 추가할까요, 아니면 전체 스케줄을 초기화한 뒤 등록할까요?

붙여넣기로 일괄 등록

한 줄에 회원 한 명씩, "이름 요일시간..." 형식으로 붙여넣으세요. 시간은 오후 기준(12 = 정오, 1~11 = 오후 1~11시)이며, 미리보기에서 해석 결과를 확인한 뒤 등록합니다.

예시) 입력 → 등록되는 시작 시각

  • 홍길동 월화수5678 → 월·화·수 17:00~20:00
  • 홍길동 월57 → 월 17:00, 19:00
  • 홍길동 화목금5530 → 화·목·금 17:00, 17:30
  • 홍길동 수목3~6 → 수·목 15:00~18:00
  • 홍길동 월화6630~ 금1~ → 월·화 18:00, 18:30~마감 / 금 13:00~마감
  • 홍길동 화5까지 목4부터 금5이후 → 화 시작~17:00 / 목 16:00~마감 / 금 17:00~마감
  • 홍길동 월수금640~9 화목640 → 월·수·금 18:40~21:00 / 화·목 18:40
  • 홍길동 화45 목2,410,420 금345 → 화 16:00~17:00 / 목 14:00, 16:10, 16:20 / 금 15:00~17:00
  • 홍길동 월 4시10분~6시 → 월 16:10~18:00
  • 홍길동 금910늦은시간 → 금 21:00~22:00, 22:30
  • 홍길동 (마포)월5678 (여의도)월89 → 월 (마포점) 17:00~20:00 / 월 (여의도점) 20:00~21:00
  • 홍길동 x → 기존 가능 시간 전체 삭제
작성 규칙 자세히 보기

요일

  • 첫 단어가 이름이고, 그 뒤가 요일·시간입니다. 이름에는 띄어쓰기를 넣지 마세요.
  • 요일(월~토)은 이어 쓸 수 있고(화목), 시간 바로 뒤에 다른 요일을 이어 써도 됩니다. (예: 화7수목78 → 화 19:00 / 수·목 19:00~20:00)
  • 시간은 바로 앞에 적은 요일 묶음 전체에 적용됩니다.

시각

  • 숫자를 이어 쓰면 각각 정시입니다. 연달아 이어지는 시각(5678)은 그 사이 언제든 시작 가능한 구간(17:00~20:00)으로, 떨어진 시각(57)은 각각(17:00, 19:00) 등록됩니다.
  • 시 뒤에 30·40·50을 붙이면 분입니다. (예: 730 → 19:30, 640 → 18:40)
  • 쉼표(,)나 슬래시(/)로 나누면 조각마다 한 시각이며, 세·네 자리 숫자는 시+분으로 읽습니다. (예: 목2,410,420 → 14:00, 16:10, 16:20 — 쉼표 없이 410은 16:00, 22:00)
  • "시"·"분"을 써도 되고, 사이를 띄어 써도 됩니다. 분은 10분 단위만 가능합니다. (예: 월 4시 10분/4시20분 → 16:10, 16:20)
  • "늦은시간"은 22:30입니다. 다른 시각 뒤에 붙이면 22:30이 추가됩니다. (예: 화늦은시간 → 22:30)

범위

  • 두 시각 사이에 물결(~)이나 하이픈(-)을 넣으면 그 사이 전부입니다. (예: 3~6 = 3-6 = 3456) 앞 시각이 더 늦으면(10~1) 오류로 표시됩니다.
  • 시각 뒤에 물결 또는 "부터"·"이후"를 붙이면 그 시각부터 마감까지입니다. 물결 앞에 여러 시각을 이어 쓰면 마지막 시각만 범위가 됩니다. (예: 6630~ → 18:00, 18:30~마감)
  • 시각 앞에 물결을 붙이거나 "까지"를 붙이면 시작부터 그 시각까지입니다. (예: ~5 = 5까지 → 시작~17:00)

지점

  • 괄호로 지점을 적으면 다음 지점 표기 전까지의 시간은 그 지점에서만 가능합니다. "점"은 생략해도 됩니다. (예: (마포) = 마포점)
  • 지점을 적지 않은 시간은 회원의 기본 지점 전체에서 가능합니다.
  • 등록되지 않은 지점의 시간은 건너뛰고 미리보기에 오류로 표시됩니다.

등록 방식

  • 기존 회원의 가능 시간은 모두 지우고 붙여넣은 내용으로 교체합니다. 같은 회원을 여러 줄에 나눠 쓰면 합쳐서 등록합니다.
  • 이름 뒤에 x만 쓰면 그 회원의 기존 가능 시간을 모두 삭제합니다. (예: 홍길동 x)
  • 시간을 하나도 해석하지 못한 기존 회원 줄은 기존 시간을 그대로 두고 건너뜁니다.
  • 이름이 같은 회원이 없으면 신규 회원으로 제안되며, 미리보기에서 기존 회원·신규·건너뛰기를 고를 수 있습니다.
  • 근무 가능 시간 밖의 시각도 등록은 되지만, 스케줄 후보에는 배정되지 않습니다.

붙여넣기로 회원 일괄 등록

한 줄에 회원 한 명씩, "지점 / 구분 / 이름" 형식으로 붙여넣으세요.

작성 규칙)

  • 지점, 구분, 이름을 슬래시(/)로 구분합니다.
  • 지점을 여러 개 등록할 경우 쉼표(,)로 구분해서 씁니다. (예: 상암점, 여의도점, 마포점)
  • 구분은 "상담" 또는 "등록" 중 하나여야 합니다.

예시)

  • 여의도점 / 등록 / 홍길동
  • 상암점, 여의도점, 마포점 / 등록 / 홍길동

백업 코드로 복원

다른 기기에서 만든 백업 코드와, 그 코드를 만들 때 입력한 백업 비밀번호를 입력하세요. 복원하면 이 기기에 현재 저장된 데이터는 백업 코드의 내용으로 덮어써집니다.

모든 데이터는 이 브라우저에만 저장됩니다 (localStorage).
